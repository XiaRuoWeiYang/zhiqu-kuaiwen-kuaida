# 微信登录与分享接入

## 当前交付状态

本地v0.9.0已加入“我的”页、原生题库/我的导航、微信云开发登录调用与身份确认函数、好友分享及首页朋友圈分享。用户已选择云开发，并明确环境尚未创建，所以环境ID保持空值；未创建环境、未部署函数、未完成真实登录或设备分享验证。此前本机题库和成绩全部保留，未登录仍可正常答题。

现场AppID为 `wx3648ec706142998b`，本轮仅保留现有值，不用历史测试号覆盖它。创建环境时应关联本项目对应的小程序账号。

## 开通真实登录

1. 使用本小程序账号打开微信开发者工具，进入“云开发”，按控制台提示开通并创建环境。套餐、计费和账号权限由用户在控制台确认，本轮未创建云资源。
2. 从云开发环境设置复制完整环境ID，在 `miniprogram/config/cloud.js` 中填写 `env`；`loginFunction` 保持 `zhiquLogin`。
3. 工程已设置 `cloudfunctionRoot: "cloudfunctions/"`。在开发者工具中为云函数目录选中同一环境，右键 `cloudfunctions/zhiquLogin`，选择“上传并部署：云端安装依赖”。函数使用固定版本 `wx-server-sdk: 3.0.1`，无需在本机安装npm。
4. 确认云端出现 `zhiquLogin` 后重新编译，进入“我的”点击“微信登录”。真机上核对成功、失败重试、退出保留成绩、再次进入/重启恢复等行为。若函数不存在或网络失败，页面仍应保持未登录。

该函数只供当前小程序的 `wx.cloud.callFunction` 调用，不配置HTTP等公开触发器，也不供混合客户端复用。云函数从 `getWXContext()` 取得微信身份，不信任客户端上传的openid；如果后续增加成绩云同步或其他账号数据操作，仍必须在云端逐次用微信上下文鉴权，不能相信客户端的 `loggedIn` 状态或自行传来的身份字段。

## 登录与数据范围

- 此处是云开发的微信身份确认流程，不需要把 `wx.login` 的临时code当成已登录，更不需要在前端放置AppSecret。云开发自动透传微信身份，不另外签发自定义token。
- 云函数只返回本次调用的openid和appid；前端内存保存身份，并校验返回appid与当前小程序匹配。不返回session_key，不在分享参数中携带身份，不写日志打印身份。
- 本地存储仅新增“下次恢复登录”的布尔标记。每次重新运行后恢复登录，仍需云端确认；仅有这个标记不显示为已登录。缺环境、函数未部署、超时或失败都不产生成功状态。
- “退出登录”只退出本应用展示的登录状态与恢复记忆，不会退出微信账号，也不会删除成绩或撤回微信平台自身的身份识别能力。
- 当前不读取微信头像、昵称、手机号，使用默认头像与“微信答题玩家”名称，不伪称已获取个人资料。暂未做云端用户资料库、排行榜或跨设备成绩同步，成绩仍保存在本机。

依据：[CloudBase小程序云函数调用与身份透传说明](https://docs.cloudbase.net/recipes/add-cloud-function-wechat-miniprogram)、[实例复用与调用来源说明](https://docs.cloudbase.net/cloud-function/instance)、[微信官方服务端SDK定义](https://github.com/wechat-miniprogram/wx-server-sdk/blob/master/index.d.ts)。微信开发文档部分直连本轮不可访问，另以官方SDK与CloudBase文档核对。

## 分享行为

- 按用户要求，四页统一用微信右上角三个点菜单分享，不提供页面独立分享按钮。答题页分享当前题库，结算页的分享标题包含自己本局分数。
- 使用原生菜单与 `onShareAppMessage`，由用户选择朋友或群，不自动发送；没有“已送达”判断或分享奖励。
- 好友分享统一落到 `/pages/home/home`，可附经过白名单验证的 `category` 参数。收到后首页展示对应邀请和开始按钮，朋友主动开启新一局；不会读取或展示发送方的结算缓存，也不会自动开始10秒计时。
- 首页另提供 `onShareTimeline` 和右上角朋友圈菜单；朋友圈仅带合法题库参数，不带个人成绩、身份或答案。其他页面仅提供好友分享，避免把本机结算页直接作为朋友圈落地页。
- 不指定他人角色图或新生成图片；当前使用微信默认页面分享展示。分享可用性、开发版/体验版访问权限与实际客户端展示需要设备复测；没有上传或发布小程序。
- 分享菜单打开时若小程序转入后台，原答题真实截止时间规则仍生效，返回时可能超时；本轮没有暂停原10秒规则。

官方API参考：[Page分享回调](https://developers.weixin.qq.com/miniprogram/dev/reference/api/Page.html)、[showShareMenu](https://developers.weixin.qq.com/miniprogram/dev/api/share/wx.showShareMenu.html)、[微信官方API类型](https://github.com/wechat-miniprogram/api-typings)。接口代码已做本地检查，实际分享未自动发送。

## 自检

运行 `node tools/check.cjs`，自动执行 `tools/check-wechat.cjs`。覆盖缺配置拒绝登录、身份确认、恢复时不信任本地缓存、重复请求合并、身份结果无效、网络失败、超时、退出竞态、旧成绩保留、云函数不接受伪造openid，以及九类分享参数与首页邀请解析。使用接口替身，不触发线上登录或分享，不代表真机验收。
